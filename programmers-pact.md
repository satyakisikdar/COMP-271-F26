# Programmer's Pact - Python 
* break and continue shall be used only on days the Cubs defeat the Cardinals 7-2.
* Methods that return values shall have only one return statement unless it can be demonstrated that they need more than one such statements.
* Methods that return no value shall have zero return statements.
* All class variables shall be _private unless you justify in comments why they need to be public.
* Code shall always have comments.
* Code will be neat and clean.
* No unauthorized imports.
* Code shall execute.
* No magic values.
